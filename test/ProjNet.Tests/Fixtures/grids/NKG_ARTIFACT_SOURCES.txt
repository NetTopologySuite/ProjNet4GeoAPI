NKG builtins test artifacts
===========================

These files are vendored locally so the NKG GIE regressions do not depend on live
network access:

1. NKG
2. eur_nkg_nkgrf03vel_realigned.tif
3. eur_nkg_nkgrf17vel.tif
4. no_kv_NKGETRF14_EPSG7922_2000.tif

Repository use
--------------

These fixtures are used by the builtins NKG URN regression coverage in
spec\PROJ\test\gie\nkg.gie. The Norway-specific GeoTIFF grid is required for the
official PROJ pipeline behind NKG::ITRF2014_TO_NO. The vendored Norway copy is
stored in strip-based layout because the current ProjNet GeoTIFF xyz-grid loader
does not accept tiled scanline reads for this path.
