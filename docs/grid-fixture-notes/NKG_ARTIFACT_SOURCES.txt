NKG builtins test artifacts
===========================

All repository paths in this note are relative to the repository root.

These files are vendored locally so the NKG builtins regression coverage in
`src\ProjNet4GeoAPI\` does not depend on live network access:

1. `src\ProjNet4GeoAPI\test\ProjNet.Tests\Fixtures\grids\NKG`
2. `src\ProjNet4GeoAPI\test\ProjNet.Tests\Fixtures\grids\eur_nkg_nkgrf03vel_realigned.tif`
3. `src\ProjNet4GeoAPI\test\ProjNet.Tests\Fixtures\grids\eur_nkg_nkgrf17vel.tif`
4. `src\ProjNet4GeoAPI\test\ProjNet.Tests\Fixtures\grids\no_kv_NKGETRF14_EPSG7922_2000.tif`

Repository use
--------------

These fixtures are used by the NKG builtins regression coverage under
`src\ProjNet4GeoAPI\test\ProjNet.Tests\Fixtures\gie\nkg.gie` together with the
vendored grid definitions in
`src\ProjNet4GeoAPI\test\ProjNet.Tests\Fixtures\grids\NKG`.

The Norway-specific GeoTIFF grid is required for the official pipeline behind
`urn:ogc:def:coordinateOperation:NKG::ITRF2014_TO_NO`. The vendored Norway copy
is stored in strip-based layout because the current ProjNet GeoTIFF xyz-grid
loader does not accept tiled scanline reads for this path.
